# 「小测」MVP 版设计文档（P0 阶段更新）

## 一、文档概述

### 1. 项目目标

打造一款「轻量自定义题库 + 自由组卷 + 测试记录」工具，支持 TXT/MD 题库导入，本地离线使用与云端同步双模式，适配小程序 + 网页多端，核心用于个人知识点巩固与自测。

### 2. 核心边界（MVP 范围）

✅ 必做功能：



* TXT/MD 题库导入解析

* 本地 IndexedDB 离线存储

* 云端 FastAPI+MySQL 同步备份

* 自定义组卷（按标签 / 题量）

* 答题、自动判分、解析展示（新增：支持即时 / 测完后两种模式）

* 测试记录（分数、正确率、用时）

* 错题自动收集

* 内置 JS/HTML/HTTP/SQL 基础题库

* 计分方式：支持考试型 / 游戏型双模式（新增）

❌ 暂不做：



* Word/PDF 导入

* 题库分享 / 付费功能

* 多人协作 / 团队题库

* 复杂权限管理

* 防作弊、计时考试

### 3. 目标用户

个人学习者（自用巩固知识点）、小型团队内部自测（后续可扩展）

### 3. 设计模式应用（无变更）



| 设计模式      | 应用场景               | 核心价值               |
| --------- | ------------------ | ------------------ |
| 策略模式      | TXT 解析策略 / MD 解析策略 | 分开维护，后续可扩展 Word 解析 |
| 适配器模式     | 杂乱文本 → 标准题目结构转换    | 统一数据格式，降低前端处理成本    |
| 单例模式      | 本地存储管理器 / 云端同步管理器  | 统一操作入口，避免重复实例      |
| 组合模式      | 题目→试卷→测试记录层级管理     | 结构化组织数据，便于查询与统计    |
| 新增：策略模式扩展 | 考试型计分策略 / 游戏型计分策略  | 两种计分逻辑分离，便于维护与扩展   |

## 四、核心功能设计（重点更新新增需求）

### 1. 题库模块（无变更）

#### （1）内置题库



* 内容：JS 基础、HTML 基础、HTTP 基础、SQL 基础（各 20 题左右）

* 存储：前端打包内置，首次启动自动导入本地 IndexedDB

#### （2）TXT/MD 导入解析



* 导入方式：前端文件选择器上传，读取文本内容

* 解析规则（宽松容错）：


  * 题目分隔：`---`（换行分隔多题）

  * 题干：首行非选项 / 答案 / 解析的文本

  * 选项：匹配 `A.` `B.` `C.` `D.` `对.` `错.` 开头的行

  * 答案：匹配 `【答案】` 关键字后的内容

  * 解析：匹配 `【解析】` 关键字后的内容

* 解析流程：前端轻量拆分 → 后端结构化清洗 → 返回标准题目格式 → 存入本地 / 云端

#### （3）题库管理



* 功能：查看、编辑、删除题目，按标签筛选

* 权限：用户仅操作自己导入 / 内置的题库

### 2. 组卷模块（新增核心配置项）



* 组卷规则：按标签筛选题目（如仅选 "JS" 标签）+ 自定义题量（1-50 题）

* 新增配置项：

1. 答案解析展示模式：

* 即时展示：答完一题后，立即显示正确答案 + 解析

* 测完后展示：全部答题完成提交后，统一展示所有答案 + 解析

1. 计分方式选择：

* 考试型：每题 1 分，答错不扣分，总分 = 正确题数

* 游戏型：答对 +1 分，答错 -0.5 分（最低得分为 0），总分 = 正确得分 - 错误扣分

- 出题方式：随机抽取符合条件的题目，避免重复

- 试卷保存：生成试卷名称，保存题目 ID 列表 + 配置项（展示模式 / 计分方式）到本地 / 云端

### 3. 答题模块（新增交互逻辑）



* 答题流程：加载试卷（含配置项）→ 逐题作答 → 提交试卷 → 自动判分

* 新增交互逻辑（基于组卷配置）：

1. 即时展示模式：

* 答完当前题，点击「下一题」前，显示「正确答案 + 解析」

* 支持「标记题目」功能，便于后续回顾

1. 测完后展示模式：

* 答完题仅记录答案，不显示对错和解析

* 全部提交后，一次性展示所有题目「用户答案 + 正确答案 + 解析」

1. 通用交互：

* 支持上一题 / 下一题切换，记忆已作答答案

* 未作答题目标记提醒（红色圆点）

* 答题过程中可随时退出，本地缓存当前答题进度

### 4. 测试记录模块（适配新增功能）



* 记录内容：试卷名称、得分、正确率、用时、测试时间、计分模式、解析展示模式

* 功能：查看历史记录详情、重新测试（保留原组卷配置）、删除记录

* 统计展示：


  * 正确率趋势图（简单折线图）

  * 各标签知识点正确率分布

  * 不同计分模式下的得分对比（可选）

### 5. 错题本模块（无变更）



* 自动收集：测试错误的题目自动加入错题本

* 功能：错题复习（按错误次数排序）、标记已掌握（移出错题本）、添加笔记

* 复习模式：随机抽取错题组卷，针对性复测

### 6. 存储同步模块（无变更）



* 本地模式：默认开启，所有数据存储在 IndexedDB，断网可用

* 云端模式：用户登录后可开启，支持一键备份 / 同步

* 登录方式：MVP 版仅支持微信小程序授权登录（简化开发）
