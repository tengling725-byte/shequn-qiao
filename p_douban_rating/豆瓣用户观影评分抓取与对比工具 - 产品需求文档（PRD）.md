## 1. 产品概述

### 1.1 产品定位

一款**本地运行的轻量 Web 工具**，支持抓取单个豆瓣用户的观影评分数据，及两个用户的观影喜好对比，输出结构化 Excel 文件，满足用户对个人 / 他人观影数据的整理、分析需求。

### 1.2 核心价值



* 无需手动记录：自动抓取豆瓣用户 “已看电影” 数据，避免重复劳动；

* 结构化输出：数据以 Excel 格式存储，方便二次编辑、筛选；

* 直观对比：快速识别两个用户的观影重合度、评分差异，辅助社交或观影决策。

### 1.3 适用场景



* 个人：整理自己的豆瓣观影记录，生成 Excel 备份；

* 社交：对比自己与朋友的观影口味，寻找共同喜好或推荐电影；

* 分析：统计特定用户的观影偏好（如高分电影类型、评分分布）。

## 3. 非功能需求

### 3.1 界面需求



* 风格：简洁、直观、无冗余元素，中文界面，符合国内用户操作习惯；

* 适配性：支持 PC 端主流浏览器（Chrome、Edge、Firefox），兼容 1366×768 及以上分辨率；

* 交互：按钮点击反馈清晰（如变色、阴影），输入错误时输入框标红提示。

### 3.2 性能需求



* 抓取速度：单个用户数据（≤500 部电影）抓取时间≤10 秒；两个用户对比≤20 秒；

* 稳定性：网络正常情况下，抓取成功率≥95%；若抓取失败，支持重试操作。

### 3.3 安全与隐私需求



* 数据存储：所有数据仅在用户本地运行和存储，不上传至外网服务器；

* 隐私保护：不收集用户个人信息，仅抓取豆瓣公开的 “已看电影” 数据。

### 3.4 运行环境需求



* 本地运行：支持 Windows/macOS/Linux 系统，依赖 Python 环境（需在使用文档中说明依赖安装步骤）；

* 无登录要求：无需注册、登录豆瓣账号，直接输入目标用户 ID / 链接即可抓取。

### 4.2 界面交互规则



1. 模块二默认收起，点击 “展开对比” 后显示完整输入项，再次点击 “收起对比” 隐藏；

2. 输入框未填写时，“开始抓取”“开始对比” 按钮置灰（不可点击）；

3. 抓取过程中，按钮显示 “抓取中...” 并禁用，同时展示加载动画；

4. 抓取成功后，结果展示区显示下载按钮和对比数据（若为对比模块）；

5. 抓取失败时，状态提示标红，显示具体错误原因，支持用户重新输入后重试。

## 6. 技术约束与依赖



1. 后端技术：Python（推荐 Flask 框架，轻量易部署）；

2. 数据抓取：使用 requests 库请求豆瓣页面，BeautifulSoup4 解析 HTML；

3. Excel 生成：使用 pandas+openpyxl 库；

4. 前端技术：HTML+CSS+JavaScript（无需复杂框架，原生即可满足需求）；

5. 运行依赖：用户需安装 Python 3.8 及以上版本，以及 requirements.txt 中指定的依赖包。

## 8. 备注与风险提示



1. 豆瓣页面结构可能变更，导致抓取失败：需预留适配空间，后续根据豆瓣页面更新调整解析规则；

2. 抓取频率限制：豆瓣可能存在反爬机制，建议单个用户抓取间隔≥3 秒，避免 IP 被临时封禁；

3. 数据完整性：若用户 “已看电影” 超过 500 部，可能需要分页抓取（需在技术实现中处理）。
