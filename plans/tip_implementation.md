# 锦囊功能实施计划

## 目标
为每道题生成对应锦囊，并在结果页显示本次答题的10条锦囊。

## 实施步骤

### 步骤1：修改 questions.js
为每道题添加 `tip` 字段（49条专属锦囊）：

```javascript
{
  id: 1,
  type: "预期反转",
  question: "跌倒了，________",
  tip: "预期反转：打破惯性思维，本该A却选择B，如'跌倒了，爬起来再哭'",
  options: [...]
}
```

### 步骤2：修改 getRandomQuestions
返回的每道题已包含 `tip` 字段

### 步骤3：修改 game.js
- 在 `finishGame` 中提取 tips：`questions.map(q => q.tip)`
- 通过 URL 传递到结果页

### 步骤4：修改 result.js
- 接收 `tips` 参数
- 点击"玩梗锦囊"显示本次的10条锦囊（左右切换）
