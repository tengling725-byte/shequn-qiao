# 梗王争霸 HTML5版 说明文档

## 项目概述

- **项目名称**：梗王争霸
- **版本**：HTML5版
- **类型**：幽默答题类小游戏
- **技术栈**：HTML5 + CSS3 + Vanilla JS

## 核心功能

### 1. 答题系统
- 每局10道题，随机抽取
- 每题10秒倒计时
- 4个选项，单选
- 正确答案得5分，连击3次以上得50分

### 2. 计分规则
| 选项 | 得分 |
|------|------|
| 正确答案 | 5分/50分 |
| 部分正确 | 1-3分 |
| 错误 | 0分 |

### 3. 锦囊功能
- 每道题对应一个锦囊（tip）
- 答题后可在结果页查看
- 左右滑动切换10条锦囊

### 4. 幽默体检
- 根据正确题数计算体温、血型
- 根据答题时间计算脉搏：
  - <3秒：100次/分（秒接神梗）
  - 3-5秒：72次/分
  - 5-7秒：60次/分
  - >7秒：50次/分

### 5. 数据存储
- localStorage本地存储
- 存储项：totalScore、highScore、gamesPlayed、usedQuestionIds

## 技术要点

### 1. 路由实现
- 所有页面在index.html中预先定义
- 通过display:none/block切换显示
- router.navigate(pageName)控制跳转

### 2. 状态管理
- 游戏状态存储在window.gameResult对象中
- 页面间通过全局变量传递数据

### 3. 计时器
- setInterval实现10秒倒计时
- 时间到自动选择null

### 4. 触摸滑动
- 支持左右滑动切换名句/文言

## 部署说明

### Netlify部署
1. 将p_humor_h5文件夹推送到GitHub
2. 访问 https://app.netlify.com
3. Add new site → 连接GitHub仓库
4. 构建命令留空
5. 发布目录选择 p_humor_h5
6. 获取链接如 https://xxx.netlify.app
