# organize-wechat-files

将微信聊天导出的文件按年份和文件类型分类整理到指定目录。

## 功能

- 按年份（取自源文件夹子目录如 2016-01 → 2016）分类
- 按文件类型（Word/Excel/PDF/PPT/其他）分组
- PDF 进一步细分为：券商研报、白皮书、工作相关、其它
- 工作相关文件按自定义关键词分子目录
- 其他类型文件（音频、视频、图片、压缩包、文档）分类到"微信其它文件"目录

## 使用方式

```
/organize-wechat-files
```

会提示输入：
1. 源文件夹路径（微信文件目录）
2. 目标文件夹路径

## 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| source_path | 源文件夹路径 | 用户输入 |
| target_path | 目标文件夹路径 | 用户输入 |
| operation | 操作方式 | move（移动） |
| skip_existing | 已存在则跳过 | true |
| mark_empty | 标记空目录 | true |
| generate_log | 生成日志 | true |

## 工作相关关键词（预设）

元创、先风、广集、小蜂、得瑞、麦斯塔、海容、存风、容风、安风、苹起、苹一、苹二、shinefore、印芯、莱特、融卡、光子瑞利

## 分类规则

| 文件类型 | 扩展名 | 目标目录 |
|---------|--------|----------|
| Word | .doc, .docx, .docm, .rtf | 年份/Word/ |
| Excel | .xls, .xlsx, .csv, .xlsb | 年份/Excel/ |
| PDF | .pdf | 年份/PDF/ |
| PPT | .ppt, .pptx | 年份/PPT/ |
| 音频 | .mp3, .m4a, .wav | 微信其它文件/年份/音频/ |
| 视频 | .mp4, .wmv, .avi | 微信其它文件/年份/视频/ |
| 图片 | .png, .gif, .jpg, .jpeg, .webp, .avif | 微信其它文件/年份/图片/ |
| 压缩包 | .zip, .rar, .7z, .tar | 微信其它文件/年份/压缩包/ |
| 其他 | .txt, .html, .py, .xmind, .pages, .numbers等 | 微信其它文件/年份/文档/ |

## 操作说明

1. 默认操作：**移动（剪切）**，不是复制
2. 如果目标文件已存在：**跳过**
3. 源文件夹的空子目录会标记为 `_已空`
4. 会生成日志文件到目标文件夹

## 示例

```
/organize-wechat-files
源文件夹: C:\Users\xxx\wechat\file
目标文件夹: C:\整理\微信文件
```
