# HTML工具页面生成器

生成纯HTML+CSS+JS的工具类网页。

## 工作流程

1. 确认需求
   - 明确网页功能
   - 确定输入输出格式
   - 询问是否需要特殊样式

2. 生成代码
   - 单HTML文件，包含内联CSS和JS
   - 简洁美观的样式
   - 响应式设计

3. 保存文件
   - 询问用户保存路径，或保存到当前目录
   - 文件名使用描述性名称

## 代码规范

- 使用现代CSS（Flexbox/Grid）
- 原生JavaScript，无框架依赖
- 清晰的代码结构
- 美观简洁的UI
- 移动端适配
