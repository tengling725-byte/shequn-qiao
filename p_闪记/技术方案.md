## 三、核心功能实现

### 3.1 语音输入流程

```
用户录音 → Base64编码 → 调用Whisper API → 获取文字 → 调用GPT润色 → 存入数据库
```

**关键代码逻辑**：

```typescript
// 1. 语音转文字
async function transcribeAudio(audioBuffer: Buffer): Promise<string> {
  const formData = new FormData();
  formData.append('file', new Blob([audioBuffer]), 'audio.webm');
  formData.append('model', 'whisper-1');

  const response = await fetch('https://api.openai.com/v1/audio/transcriptions', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${OPENAI_API_KEY}` },
    body: formData
  });

  const data = await response.json();
  return data.text;
}

// 2. AI润色（支持风格选择）
type PolishStyle = '简洁' | '正式' | '幽默' | '文言' | '文艺' | '自定义';

const stylePrompts: Record<PolishStyle, string> = {
  '简洁': '你是一个专业的产品笔记助手，请把用户的口语记录整理成简洁、清晰的结构化文字，保持原意，去除冗余。',
  '正式': '你是一个专业的产品笔记助手，请把用户的口语记录整理成正式、专业的文字，语言规范，逻辑清晰。',
  '幽默': '你是一个有趣的朋友，请把用户的口语记录用轻松幽默的方式重新表达，保持原意但更有趣。',
  '文言': '你是一个精通文言文的学者，请把用户的口语记录用简洁的文言文风格表达，保持原意。',
  '文艺': '你是一个文艺青年，请把用户的口语记录用优美、富有文采的方式表达，保持原意但更生动。',
  '自定义': '你是一个专业的产品笔记助手，请把用户的口语记录整理成结构化、清晰的文字，保持原意但更通顺。'
};

async function polishText(text: string, style: PolishStyle = '简洁', customPrompt?: string): Promise<string> {
  const systemPrompt = style === '自定义' && customPrompt
    ? customPrompt
    : stylePrompts[style];

  const response = await fetch('https://api.openai.com/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${OPENAI_API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      model: 'gpt-4o-mini',
      messages: [{
        role: 'system',
        content: systemPrompt
      }, {
        role: 'user',
        content: text
      }]
    })
  });

  const data = await response.json();
  return data.choices[0].message.content;
}
```

### 3.5 文章导出

```typescript
// 导出为Word
async function exportToWord(content: string, title: string): Promise<Buffer> {
  const doc = new Document({
    sections: [{
      properties: {},
      children: [
        new Paragraph({
          text: title,
          heading: HeadingLevel.HEADING_1
        }),
        new Paragraph({
          text: content
        })
      ]
    }]
  });

  return await doc.render();
}

// 导出为Markdown
async function exportToMarkdown(content: string, title: string): string {
  return `# ${title}\n\n${content}`;
}

// 导出为PDF
async function exportToPDF(content: string): Promise<Buffer> {
  const pdfDoc = await PDFDocument.create();
  const page = pdfDoc.addPage();
  const { width, height } = page.getSize();
  page.drawText(content, { x: 50, y: height - 50, size: 12 });
  return await pdfDoc.save();
}
```

## 六、技术风险与应对

| 风险 | 应对方案 |
|------|----------|
| 中文语音识别不准 | 备选讯飞API，或用Whisper中文模型 |
| AI成本超出预期 | 优化prompt减少token，或用更便宜的模型 |
| 图片存储成本高 | 压缩图片 + 腾讯云COS低成本存储 |
| 并发量增长 | 后续可迁移到独立服务器 |
