## 八、核心交互流程

### 8.1 语音记录流程

```
首页 → 按住语音按钮 → 录音中 → 松开 → 转文字+AI润色 → 确认/修改 → 保存
```

### 8.2 选记录生成文章流程

```
首页/记录列表 → 进入"生成文章" → 筛选记录 → 选择记录 → 选择风格 → AI生成 → 预览 → 导出/保存
```

### 8.3 任务处理流程

```
记录中提取任务 → 任务中心显示 → 点击完成/编辑 → 同步到首页回顾
```

## 十、视觉风格建议

| 元素 | 建议 |
|------|------|
| 配色 | 浅色主题，主色#4A90D9（蓝色） |
| 圆角 | 12px，柔和友好 |
| 字体 | 思源黑体/ PingFang SC |
| 图标 | 线性图标，轻量感 |
| 间距 | 16px基准，留白充足 |
| 动效 | 录音时波形动效，页面切换平滑 |
