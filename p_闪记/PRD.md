# 「闪记」产品需求文档

## 一、产品概述

- **产品名称**：闪记
- **一句话定位**：语音驱动的轻量全能记录工具，把想法、日记、任务串起来
- **目标用户**：想法多、事情散、随时记录的人（职场人、大学生、自由职业者）
- **核心价值**：用语音高效记录 → AI自动润色 → 串起零散的想法和任务

---

## 二、核心功能

### 2.1 输入功能

| 功能 | 描述 | 备注 |
|------|------|------|
| 语音输入 | 按住说话 → 语音转文字 → AI润色 → 结构化存储 | 微信小程序原生支持 |
| 文字输入 | 手动打字 → AI润色 | 同样享受AI整理 |
| 图片配图 | 输入时可粘贴/上传图片，作为记录配图 | 存云端（腾讯云COS） |

### 2.2 AI 功能

| 功能 | 描述 | 备注 |
|------|------|------|
| AI润色 | 自动整理口语为结构化文字，**可选风格** | 使用GPT-4o mini |
| AI润色风格 | 简洁/正式/幽默/文言/文艺/自定义 | 默认简洁风 |
| 自动标签 | AI自动打标签（#日记、#任务、#想法、#灵感） |  |
| 任务提取 | 自动识别待办事项，加入任务列表 |  |

#### AI润色风格说明

| 风格 | 适用场景 | 示例 |
|------|----------|------|
| **简洁** | 快速记录、待办事项 | "下午3点开会讨论项目" |
| **正式** | 工作汇报、会议纪要 | "今日下午15:00召开项目讨论会议" |
| **幽默** | 日常随笔、生活记录 | "今天又给自己的拖延症加了把火~" |
| **文言** | 情怀记录、文艺青年 | "今日所得，犹胜昨日" |
| **文艺** | 读书笔记、感悟记录 | "阳光洒在书页上，思绪也随之飘远..." |
| **自定义** | 用户自定义prompt | 用户自行设置偏好风格 |

> 注：风格选择仅影响AI润色的表达方式，不影响内容结构和标签提取。

### 2.3 内容生成

| 功能 | 描述 | 备注 |
|------|------|------|
| 今日回顾 | 每天自动生成一份"今日小结" | 免费 |
| 选记录成文 | 手动选历史记录 → AI串成完整文章 | 可按时间段/类型筛选 |
| 导出功能 | 导出为Word/MD/PDF格式 | 每月免费5条，超出付费 |

### 2.4 访问

| 功能 | 描述 | 备注 |
|------|------|------|
| 多端访问 | 电脑和手机都可访问 | 微信小程序 + Web版 |

## 三、用户痛点

1. **想法散**：灵感总是突然出现，但过后就忘
2. **工具多**：日记App、任务App、笔记App切换麻烦
3. **记录累**：打字太慢，语音没有好工具
4. **串不起来**：历史记录像碎片，无法形成连续思考

---

## 四、目标用户画像

### 4.1 核心用户

- **职场人**：会议纪要、项目想法、日常待办
- **大学生**：课堂笔记、社团事务、学习规划
- **自由职业者**：客户需求、创意灵感、日常行程

### 4.2 共同特征

- 想法多、事情杂
- 习惯用手机记录
- 对效率有追求
- 愿意尝试新工具

---

## 五、MVP范围（V1必须做）

1. 语音/文字输入 → AI润色 → 存储
2. **AI润色风格选择**（简洁/正式/幽默/文言/文艺/自定义）
3. 图片配图功能
4. 自动标签分类
5. 今日回顾
6. 任务提取
7. 选记录生成文章（基础版）
8. 文章导出（每月5条免费）
9. 微信登录
10. 基础筛选（时间、标签）

**V1明确不做的**：
- 高级AI搜索
- 周报/月报生成
- 社区/社交功能
- 多设备数据同步
- 复杂的数据导出

---

## 六、非功能需求

### 6.1 性能

- 语音转文字延迟 < 3秒
- AI润色延迟 < 2秒
- 页面加载 < 1秒

### 6.2 存储

- 免费用户: 1GB存储
- 图片压缩存储

### 6.3 安全

- 数据加密存储
- 微信登录鉴权
- 用户隐私保护

---

## 七、竞品分析

| 竞品 | 优点 | 不足 |
|------|------|------|
| Notion | 功能全面 | 太重，学习成本高 |
| 微信文件传输助手 | 随时可用 | 无结构、无AI |
| 飞书文档 | 协作好 | 不适合个人记录 |
| Day One | 体验好 | 无AI、无任务串连 |
| 闪记（我们） | 语音+AI+串连 | 从0开始 |

**差异化定位**：轻量 + 语音优先 + AI串连

---

## 八、风险与待验证

1. **假设1**：用户真的愿意用语音记录，而不是打字
2. **假设2**：中文语音转文字准确率（需测试）
3. **假设3**：AI润色效果能让用户满意
4. **假设4**：用户愿意为导出功能付费
5. **风险1**：图片存储成本控制
6. **风险2**：多端数据同步复杂度
