# 「社群桥」产品需求文档

## 一、产品概述

- **产品名称**：社群桥
- **一句话定位**：社群会员资源与需求的智能匹配平台，把群体力量激发出来
- **目标用户**：社群组织者、认证会员（校友群、行业群、商会、创业社群等）
- **核心价值**：让会员定义自己的资源+需求，随时搜索匹配，精准对接

---

## 二、目标社群

### 第一批

1. **北京大学半导体校友群** - 半导体行业从业者校友
2. **香港高才群** - 香港高才计划人群，开公司找合伙人等需求

### 后续扩展

- 其他校友群
- 行业群
- 商会社群
- 创业社群

## 三、核心功能

### 3.1 会员资料管理

| 功能 | 描述 | 备注 |
|------|------|------|
| 个人信息 | 姓名、头像、公司、职位、联系方式 | 认证后可完善 |
| 资源定义 | 长期资源 + 短期资源 | 可编辑、可隐藏 |
| 需求定义 | 长期需求 + 急需 + 未来3月 + 自定义时间 | 可编辑、可隐藏 |
| 隐私设置 | 资源/需求是否公开 | 默认仅认证会员可见 |

### 3.2 资源与需求分类

**资源分类**：

| 类型 | 说明 | 示例 |
|------|------|------|
| 长期资源 | 长期可复用的能力/资源 | 行业经验、人脉渠道、资金、专业技能 |
| 短期资源 | 临时性资源 | 短期兼职、临时场地、设备租借 |

**需求分类**：

| 类型 | 说明 | 示例 |
|------|------|------|
| 长期需求 | 持续存在的需求 | 找合伙人、扩展渠道 |
| 急需 | 紧急需求，时效性强 | 本周需要设计师、急招岗位 |
| 未来3月 | 计划中的需求 | 3个月后需要融资 |
| 自定义 | 用户自定义时间 | 指定日期范围 |

### 3.3 匹配功能

| 功能 | 描述 | 备注 |
|------|------|------|
| 主动搜索 | 按关键词/分类搜索资源/需求 | 支持模糊搜索 |
| 智能推荐 | 系统推荐匹配的资源/需求 | 基于标签匹配 |
| 匹配通知 | 当新资源/需求匹配时通知用户 | 推送通知 |
| 收藏 | 收藏感兴趣的资源/需求 | 便于后续查看 |

### 3.4 社群管理

| 功能 | 描述 | 备注 |
|------|------|------|
| 社群创建 | 创建新社群，设定规则 | 仅管理员 |
| 会员认证 | 审核会员加入，验证身份 | 认证制 |
| 数据统计 | 资源数量、需求数量、匹配次数 | 运营参考 |
| 内容管理 | 删除违规内容 | 仅管理员 |

### 3.5 增值服务（V2）

| 功能 | 描述 | 备注 |
|------|------|------|
| 置顶 | 资源/需求置顶显示 | 付费 |
| 精准推送 | 付费精准推送给相关会员 | 付费 |
| 数据分析 | 社群资源分析报告 | 付费 |

## 四、用户角色

| 角色 | 权限 |
|------|------|
| 普通访客 | 浏览公开信息（可选） |
| 认证会员 | 查看所有会员的资源+需求、搜索、匹配、发布 |
| 社群管理员 | 社群管理、会员审核、内容管理、数据统计 |

---

## 五、MVP范围（V1必须做）

1. 会员注册 + 认证
2. 资源定义（长期+短期）
3. 需求定义（长期+急需+未来3月+自定义）
4. 主动搜索
5. 智能推荐（基础版）
6. 隐私设置
7. H5上线

**V1明确不做的**：
- 付费增值功能
- 复杂的数据分析
- 社群多级权限
- 消息IM功能
- 复杂的推荐算法

---

## 六、非功能需求

### 6.1 性能

- 搜索响应 < 1秒
- 推荐加载 < 2秒
- 页面加载 < 1秒

### 6.2 安全

- 微信登录鉴权
- 资源/需求仅认证会员可见
- 内容审核机制

### 6.3 体验

- 简洁易用的表单
- 清晰的匹配展示
- 重要的匹配通知

---

## 七、用户痛点

1. **信息散乱**：资源/需求发到微信群就淹没，找不到
2. **无法精准匹配**：只能靠人工@，效率低
3. **隐私问题**：公开在群里尴尬，不公开没人知道
4. **时效性**：急需的需求容易被错过

---

## 八、竞品分析

| 竞品 | 优点 | 不足 |
|------|------|------|
| 微信群 | 随时可用、门槛低 | 信息淹没、无法搜索、隐私差 |
| 脉脉 | 职场社交 | 非专为社群设计、功能杂 |
| 垂直社群平台 | 功能专一 | 通常付费、定制性差 |

**差异化定位**：专为中国式社群设计，轻量+免费+隐私保护

## 十、风险与待验证

1. **假设1**：会员愿意主动定义自己的资源和需求
2. **假设2**：会员愿意搜索和查看别人的资源/需求
3. **假设3**：匹配后能产生实际对接
4. **风险1**：用户发布信息后缺乏后续互动
5. **风险2**：社群活跃度随时间下降
