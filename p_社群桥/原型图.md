## 九、核心交互流程

### 9.1 发布流程

```
登录 → 选择发布类型（资源/需求） → 选择时间类型 → 填写分类 → 填写标题和描述 → 设置隐私 → 发布
```

### 9.2 匹配流程

```
浏览资源/需求 → 点击详情 → 点击"对接" → 系统通知对方 → 双方线下对接
```

### 9.3 搜索流程

```
首页搜索框 → 输入关键词 → 筛选（资源/需求/分类/时间） → 查看结果 → 点击详情
```

## 十、视觉风格建议

| 元素 | 建议 |
|------|------|
| 配色 | 主色#2563EB（蓝色），辅助#10B981（绿色） |
| 标签 | 用颜色区分：长期=蓝，急需=红，短期=橙 |
| 圆角 | 12px，柔和友好 |
| 字体 | 思源黑体/ PingFang SC |
| 间距 | 16px基准 |
| 紧急标识 | 红色标签+火焰图标 |
