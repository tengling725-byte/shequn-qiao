# PDF图表目录提取工具

本工具从PDF文件中提取图表目录，生成CSV格式的索引文件。

## 使用场景

当用户称呼"小汪"并要求：
- "生成图表目录"
- "提取图表索引"
- "生成PDF的图表CSV"
- 对某个文件或文件夹生成图表目录

## 功能特点

1. **支持单个PDF文件**：提取图表目录并生成CSV
2. **支持文件夹**：批量处理文件夹内所有PDF，结果合并到一个CSV
3. **自动识别图表表头**：原样提取"图表1"、"图1"、"表1"等
4. **提取真实页码**：从图表目录中提取实际页码
5. **记录无法提取的文件**：若PDF无图表目录，会记录文件信息

## 输出CSV格式

| 列 | 说明 |
|---|---|
| 来源文件 | PDF文件名 |
| 图表表头 | 原样：图表1/图1/表1 |
| 图表标题 | 图表标题文字 |
| 页码 | 实际页码 |
| 链接 | PDF路径+#page=页码 |
| HYPERLINK公式 | Excel超链接公式 |

## 输出文件位置

- 单文件：`原文件名_chart_index.csv`（同目录）
- 文件夹：`文件夹名_chart_index.csv`（放入文件夹内）

## 使用方法

### 命令行
```bash
python generate_chart_index.py <文件或文件夹路径>
```

### 示例
```bash
# 处理单个PDF
python generate_chart_index.py "C:\文档\报告.pdf"

# 处理文件夹
python generate_chart_index.py "C:\文档\行业研究报告"
```

## 状态输出

程序会显示处理进度：
- 检测到文件夹时显示文件数量
- 每个文件显示提取状态
- 最终显示生成的索引数量和文件位置

## 依赖

- pypdf
- pdfplumber
- Python 3.x
