这是一份**题库编写用户指南**，帮助你了解 Parser 能识别哪些格式，避免出现解析错误。

---

# 题库编写用户指南

## 一、基本结构

每道题由四个部分组成：**题干**、**选项**、**答案**、**解析**。四个部分的出现顺序可以任意，Parser 会自动识别。

---

## 二、题干（题目文字，可以换行）

### 支持的标记词（中英文均可）

| 中文  | 英文     | 其他变体       |
| ----- | -------- | -------------- |
| 题干  | Question | 题目、问题     |
| 第N题 | No.N     | 题N、第N题、N. |

### 正确示例

```
题干：以下关于 Python 的说法正确的是？

Question: Which of the following is correct about Python?

第1题 以下关于 JavaScript 原型链的说法，正确的有？

题2: 下列哪些是 CSS 选择器？

1. 以下关于 Git 的说法正确的是？

【问题】什么是闭包？

Problem: What is a closure?
```

### 错误示例（无法识别）

```
以下关于 Python 的说法正确的是？   ← 没有标记词，会被当作纯文本
```

---

## 三、选项（A/B/C/D...）

### 支持的标记格式

| 格式            | 示例            |
| --------------- | --------------- |
| 字母 + 点       | `A. 选项内容`   |
| 字母 + 顿号     | `A、选项内容`   |
| 字母 + 冒号     | `A: 选项内容`   |
| 字母 + 右括号   | `A) 选项内容`   |
| 字母 + 中文括号 | `（A）选项内容` |
| 字母 + 英文括号 | `(A) 选项内容`  |
| 字母 + 方括号   | `【A】选项内容` |
| 字母 + 空格     | `A 选项内容`    |

### 正确示例

```
A. 每个对象都有 __proto__ 属性
B. 每个函数都有 prototype 属性
C. Object.prototype 是原型链顶端

A、margin 是外边距
B、padding 是内边距
C、border 是边框

A) 队列
B) 栈
C) 链表

（A）分治算法
（B）动态规划
（C）贪心算法

A 前端框架
B 后端框架
C 数据库
```

### 错误示例（无法识别）

```
1. 选项1   ← 不支持数字编号
2. 选项2

- B 选项内容
```

---

## 四、答案（正确答案）

### 支持的标记词（中英文均可）

| 中文   | 英文    | 其他变体                           |
| ------ | ------- | ---------------------------------- |
| 答案   | Answer  | 正确答案、标准答案、参考答案、正解 |
| 答案： | Answer: | 答案：、答案：                     |

### 支持的答案格式

| 格式        | 示例      | 解析结果        |
| ----------- | --------- | --------------- |
| 连续字母    | `ABC`     | `["A","B","C"]` |
| 字母 + 逗号 | `A,B,C`   | `["A","B","C"]` |
| 字母 + 顿号 | `A、B、C` | `["A","B","C"]` |
| 字母 + 空格 | `A B C`   | `["A","B","C"]` |
| 单个字母    | `A`       | `["A"]`         |

### 正确示例

```
答案：ABC
答案：A,B,C
正确答案：A、B、C
标准答案：A B C
Answer: ABC
a,b,c   ← 小写也会被转为大写
答案：A   ← 单选题
```

### 错误示例（无法识别）

```
答案：AB3   ← 包含非字母字符
答案：A,B,C,D   ← 如果 D 不存在于选项中，仍会解析但业务层会校验
```

## 五、解析（题目解释，可以换行）

### 支持的标记词（中英文均可）

| 中文 | 英文        | 其他变体                                     |
| ---- | ----------- | -------------------------------------------- |
| 解析 | Explanation | 讲解、解释、注解、详细解析、解答、解释、详解 |

### 正确示例

```
解析：A、B、C 正确。D 错误，因为...

讲解：这道题考察的是原型链的概念。

解析：
A、B、C 正确。D 错误，因为...
所以A正确

Explanation: Option A is correct because...

详解：margin 是外边距，padding 是内边距。
```

## 六、题目之间的分隔

### 支持的分隔方式

| 方式         | 示例                       |
| ------------ | -------------------------- |
| 空行（推荐） | 两道题之间留一个或多个空行 |
| 分隔线       | `---` 或 `###`             |

### 正确示例

```
题1：xxx
A. xxx
B. xxx
答案：A
解析：xxx

题2：yyy
A. yyy
B. yyy
答案：B
解析：yyy
```

## 七、完整示例模板

你可以直接复制以下模板来编写题目：

```
【题干】这里写题目内容，支持多行
【选项】
A. 选项1
B. 选项2
C. 选项3
【答案】ABC
【解析】这里写解析内容，支持多行
```

或者更简洁的风格：

```
第1题 题目内容
A. 选项1
B. 选项2
C. 选项3
答案：A
解析：这是正确答案的解释。
```

## 八、常见问题（FAQ）

### Q1：题目内容可以换行吗？
**可以。** 题干和解析都支持多行文本，Parser 会一直读取到下一个标记词为止。

### Q2：选项可以跨行吗？
**不可以。** 每个选项应该写在一行内。如果选项内容很长，建议手动换行成多句，或者保持一行。

### Q3：答案可以包含小写字母吗？
**可以。** `abc` 会被自动转为 `["A","B","C"]`。

### Q4：一道题可以没有解析吗？
**可以。** 解析部分是可选的。

### Q5：一道题可以没有选项吗？
**不可以。** 没有选项的题无法作答，会被跳过或报错。

### Q6：我能混合使用中文和英文标记吗？
**可以。** 例如题干用「问题」，答案用「Answer」，解析用「详解」，Parser 都能识别。

### Q7：选项字母必须大写吗？
**不必须。** `a.` `b.` 小写字母也会被识别，但建议统一使用大写。

## 九、快速检查清单

在提交题库前，请检查以下几点：

- [ ] 每道题都有**题干**标记词（题干/题目/第N题等）
- [ ] 每道题都有**选项**，且选项字母为 A-G
- [ ] 每个选项独占一行
- [ ] 每道题都有**答案**，答案字母在选项范围内
- [ ] 不同题目之间用**空行**分隔
- [ ] 标记词后面有**冒号或空格**（不是必须，但推荐）
